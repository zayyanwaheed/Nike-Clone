# Nike-Clone

A modern interactive Nike-style ecommerce clone built with Next.js, TypeScript, Tailwind CSS, animated product cards, quick view, cart, wishlist, search, and checkout flow.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
